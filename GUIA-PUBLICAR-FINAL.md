## ▶️ PUBLICAR (5 min — mesmo esquema de sempre)
1. Extraia o zip
2. GitHub → repositório → **Add file → Upload files**
3. **Arraste TUDO junto**: os 4 arquivos .html/.ico da raiz + a pasta `assets`
   (o GitHub avisa "files with the same name" → **normal**, substitui)
4. Commit → espere 2–3 min → **Ctrl+F5** (ou aba anônima)
5. Confira: `https://www.aquitemachadinhos.com.br/`
